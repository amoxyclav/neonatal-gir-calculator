# Security and privacy

This project is a client-side static web application. Patient inputs are intended to remain in the user's browser and are not intentionally transmitted to a project server by the calculator.

## Do not submit patient information

GitHub Issues are public. Never include patient names, identifiers, photographs, medical-record screenshots, or other protected/personal information in issues, pull requests, or discussions. Use fictional examples when reporting calculation problems.

## Reporting a security issue

If you discover a security vulnerability affecting the website or repository, do not post exploit details in a public issue. Contact the repository owner through GitHub's private contact mechanisms and provide enough information to reproduce the problem without sharing patient information.

## Clinical safety

A security review does not constitute clinical validation. The calculator remains a calculation aid and does not replace clinical judgment, product-label verification, pharmacy preparation procedures, line-access checks, compatibility checks, or local NICU protocols.

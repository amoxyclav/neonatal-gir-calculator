Quick Start Guide

  1. GIR Calculator: Enter weight, TFI and target GIR. Add only the fluids actually being administered. Review the current GIR, remaining TFI and nutrition contribution, then review or edit the interactive target GIR plan.
  2. Energy-Protein Ratio: The Nutrition page mirrors the patient inputs and current fluids from GIR. The automatic GIR plan is assumed to be added for nutrition calculations. Enter HMF, HMF-Advance or MCT quantities when used and review the resulting energy, protein/AA, carbohydrate and Energy-Protein ratio.
  3. Fluid Mixer: Use Making a New Bag when preparing a target concentration from two stock concentrations. Use Adjusting an Existing Bag when you already have a fluid and need to add a stock solution to reach a target concentration.
  4. Preset compositions can be expanded and edited where permitted. Blank quantity fields are treated as zero. Always verify the actual product label, concentration, compatibility, preparation method, line access and local NICU protocol before administration.

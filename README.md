# Neonatal GIR & Nutrition Calculator

Static neonatal GIR, TFI-aware target planning, nutrition and fluid-mixer calculation aid.

Current release: v1.4

This is a calculation aid, not a prescribing system or validated medical device. Verify product identity, concentrations, compatibility, line access, preparation and local NICU protocols before clinical use.

Patient-specific concentration overrides are permitted only for Aminoven, Isolyte P and Intralipid. Aminoven contributes amino acids and calories but 0 GIR. Aminoven defaults: 5% = 5 g amino acids + 20 kcal/100 mL; 10% = 10 g + 40 kcal/100 mL.

The repository is the source of truth for the published website.
